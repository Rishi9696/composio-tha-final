04 · Method

Evidence first. Decisions second.

OpenAI synthesizes fetched evidence into a locked schema; deterministic checks own citations, catalog identity, and executable toolkit depth.

  1. 01SDK coverage audit

    The Composio SDK classifies every app as active, catalog-only, or missing and records tool depth.

    --composio-audit
  2. 02Docs research

    OpenAI web search plus direct fetch collect official API, auth, access, and MCP pages.

    docs_research.py
  3. 03Schema synthesis

    OpenAI returns a locked 19-field record with cited URLs via structured output.

    synthesis.py
  4. 04Deterministic gate

    Invalid labels, weak coverage, contradictions, and invented links fail closed.

    schema.py
  5. 05Official-doc check

    Priority apps are adjudicated against vendor docs, with every recorded miss preserved.

    handcheck.py
  6. 06Session diagnostic

    A read-only OpenAI Session runs one bounded Browser Tool investigation and deterministic comparison.

    --composio-agent
